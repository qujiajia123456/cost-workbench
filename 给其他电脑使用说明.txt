成本部工作台使用说明

1. 请把整个“成本部工作台_测试版”文件夹复制到其他电脑，不要只复制 bat 文件。
2. 进入文件夹后，双击“start_windows.bat”启动。
3. 正常启动后浏览器会打开：http://127.0.0.1:8899/
4. 使用过程中不要关闭黑色命令窗口；关闭窗口后网页也会停止。
5. 如果双击没有反应，右键“start_windows.bat”，选择“以管理员身份运行”再试。
6. 如果仍不能启动，双击“diagnose_windows.bat”，把窗口里的提示或截图发回来。

说明：
- 文件夹里已带便携 Python，通常不需要在电脑上单独安装 Python。
- 不建议放在很深的路径或带特殊符号的路径下，推荐放在 D:\成本部工作台_测试版 或桌面。
- 第一次打开如果浏览器拦截，请手动访问 http://127.0.0.1:8899/

复制给别人前：
1. 推荐先在本机运行 package_for_distribution.ps1，生成 dist\成本部工作台_分发版_日期时间 文件夹。
2. 默认分发版只带程序、模板和空数据，不带本机上传记录、导出成果、浏览器登录缓存和调试日志。
3. 如果确实要连当前业务数据一起复制，运行：
   powershell -ExecutionPolicy Bypass -File .\package_for_distribution.ps1 -IncludeBusinessData
4. 不建议直接复制 .git、.agents、.venv、__pycache__、浏览器 profile、日志和 saved/backup 历史快照。

目标电脑环境：
1. 系统：Windows 10/11 或 Windows Server。
2. 浏览器：Edge、Chrome 或 360 极速模式均可。
3. Python：需要 Python 3.10 或以上版本。
4. 如果目标电脑能联网，双击 start_windows.bat 会自动创建 .venv 并安装 openpyxl。
5. 如果目标电脑没有 Python 但能联网，脚本会尝试用 winget 安装 Python。
6. 如果目标电脑不能联网，请提前准备 Python 和依赖包：
   - 把 Python 官方安装包放到 vendor\python-installer.exe，或准备便携 Python 到 .runtime\python\python.exe；
   - 同时把依赖包 wheel 放到 vendor\wheels，当前至少需要 openpyxl。
7. 当前 vendor 目录只放了说明文件，没有 Python 安装包，也没有离线 wheel；发给没有 Python 且不能联网的电脑前，需要先补齐。

黑名单关联查询与 Codex 说明：
1. 普通电脑不需要安装 Codex，只需要打开网页小程序。
2. 点击“天眼查穿透”后，网页会把任务提交到小程序服务器的数据目录。
3. 只需要固定一台安装 Codex 的中心电脑处理这些任务。
4. 中心电脑双击 start_blacklist_codex_worker.bat，可查看下一条待处理任务。
5. Codex 按任务说明使用天眼查或授权企业信息数据源查询后，将结果写回 data\blacklist_results。
6. 普通电脑刷新网页或重新查询，即可看到关系图并导出 Excel。
